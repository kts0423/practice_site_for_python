# 🐍 Python Practice Website

**Python Practice Website**는 파이썬 문법 학습을 위한 웹 기반 학습 플랫폼입니다. 사용자가 다양한 문법 문제를 풀고, GPT 기반 해설을 통해 학습 효과를 높일 수 있도록 설계되었습니다.

## 🎓 프로젝트 개요

- 파이썬 초급 학습자를 위한 실습 환경 제공
- GPT API를 활용한 자동 문제 해설 시스템 구현
- 정답률 기반의 문제 난이도 조정 및 히스토리 관리 기능 포함

## 🔧 주요 기능

- ✅ **로그인/회원가입 시스템**
- ✅ **문제 자동 생성 및 실시간 채점**
- ✅ **오답 시 GPT 기반 해설 제공**
- ✅ **풀이 히스토리 저장 및 날짜/카테고리 필터링**
- ✅ **정답률 시각화 (그래프)** 및 학습 추이 확인 기능

## 🖼️ 시나리오

1. **학생 로그인 → 실습 문제 풀이**
2. **정답 제출 → 채점 + GPT 해설**
3. **히스토리 페이지에서 복습**

## ⚙️ 사용 기술

- **Frontend**: HTML, CSS (Dark Mode), JavaScript
- **Backend**: Python Flask, Jinja2
- **DB**: SQLite (간단한 사용자 및 히스토리 저장)
- **AI API**: OpenAI GPT API
